## Capability matrix (single source: `src/Admin/Security/Capability.php`; print with `php bin/console picklers:admin:privilege matrix`)

| Capability | Admin | Privileged admin |
|---|---|---|
| Open the console; review applications; view private documents; manage facilities/courts; manage bookings; verify users; send individual notices; reset non-admin passwords; deactivate/reactivate non-admins; switch player↔owner; moderate content; manage promos; view ledger, reports, audit, system; export CSV | yes | yes |
| Grant/remove administrator role; grant/revoke privileged admin; deactivate an administrator; reset an administrator's password; permanently delete accounts; wallet credit/debit; impersonate; broadcast | no | yes |

Legacy administrators are **not** auto-promoted. The first privileged administrator is granted by an operator: `php bin/console picklers:admin:privilege grant <email> --reason="…"` (audited, actor `console`).

## Every admin action

All 43 `admin_*` action names (plus the `switch_user` alias) are listed with parameters in `route-map.md`. Coverage: each is asserted to refuse a non-admin (`SecurityTest::testEveryDeclaredActionIsRoutedAndGuarded`); every read action returns 200 for an admin (`testEveryReadActionAnswersForAnAdmin`, which also checks the `admin_delete_user` legacy alias), and every mutating action is exercised in the R-specific test classes above.
